01 · Hallazgos01 · Findings

Lo que la IA escribe rápido y nadie revisaWhat AI writes fast and nobody reviews

Las herramientas de IA resuelven la tarea, pero no piensan en quién más puede ver el código. Estos son los problemas que más encontramos en empresas pequeñas y medianas.AI tools get the task done, but they don't think about who else can see the code. These are the problems we find most often in small and mid-size companies.

CríticaCritical

Llaves de pago escritas en el códigoPaid API keys written in the code

// src/chat.js
const openai = new OpenAI({
  apiKey: "sk-proj-Xq7…redactada"
});

Cualquiera con acceso al repositorio puede usar tu cuenta. Una llave filtrada puede generar miles de dólares de consumo en una noche.Anyone with access to the repository can use your account. A leaked key can run up thousands of dollars overnight.

Cómo lo dejamos:How we leave it: llave revocada y rotada, guardada como variable de entorno.key revoked and rotated, stored as an environment variable.

CríticaCritical

Base de datos abierta al públicoDatabase open to the public

-- Supabase, tabla "clientes"
Row Level Security: OFF
-- la llave pública lee todo

Apps hechas con Lovable, Bolt o v0 suelen salir así. Con la llave que va en la página web se pueden descargar nombres, teléfonos y direcciones.Apps built with Lovable, Bolt or v0 often ship like this. The key that ships in the web page is enough to download names, phones and addresses.

Cómo lo dejamos:How we leave it: reglas de acceso por usuario, listas para aplicar.per-user access rules, ready to apply.

AltaHigh

Contraseñas en archivos .env subidosPasswords in committed .env files

$ git log --all -- .env
DB_PASSWORD=Pedidos2024!
SMTP_PASS=…

Aunque después se borre el archivo, queda en el historial. Revisamos el historial completo, no solo la versión actual.Even after the file is deleted, it stays in the history. We check the full history, not just the current version.

Cómo lo dejamos:How we leave it: contraseñas cambiadas y .gitignore que bloquea el archivo.passwords changed and a .gitignore that blocks the file.

AltaHigh

Consultas que aceptan cualquier textoQueries that accept any text

db.query(
  "SELECT * FROM pedidos WHERE id = "
  + req.query.id
);

Con un texto bien armado en la URL, un extraño puede leer o borrar la base completa (inyección SQL).With crafted text in the URL, a stranger can read or delete the whole database (SQL injection).

Cómo lo dejamos:How we leave it: consultas con parámetros, probadas.parameterized queries, tested.

AltaHigh

Paquetes que la IA inventóPackages the AI made up

$ npm install react-pdf-invoice-gen
# no existe en el registro oficial;
# un atacante puede publicarlo

La IA a veces recomienda librerías que no existen. Si alguien las registra con código malicioso, se instalan solas.AI sometimes suggests libraries that don't exist. If someone registers them with malicious code, they install themselves.

Cómo lo dejamos:How we leave it: cada dependencia verificada contra npm y PyPI.every dependency checked against npm and PyPI.

MediaMedium

Conexiones que no verifican el certificadoConnections that skip certificate checks

ssl: {
  rejectUnauthorized: false
}

La IA lo agrega para que "funcione". La conexión queda cifrada, pero sin confirmar con quién estás hablando.AI adds it to make things "work". The connection stays encrypted, but without confirming who is on the other end.

Cómo lo dejamos:How we leave it: verificación activa con el certificado correcto.verification on, with the right certificate.

Sí, es el caso más común. La app busca los proyectos en las computadoras y marca los que tienen señales de herramientas de IA.Yes, that's the most common case. The app searches the computers for projects and flags the ones with signs of AI tools.
